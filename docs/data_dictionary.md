# Data Dictionary

## Keys

- `Latitude`: latitude du point d'échantillonnage.
- `Longitude`: longitude du point d'échantillonnage.
- `Sample Date`: date de collecte de l'échantillon.

## Targets

- `Total Alkalinity`: alcalinité totale de l'eau.
- `Electrical Conductance`: conductivité électrique.
- `Dissolved Reactive Phosphorus`: phosphore réactif dissous.

## Feature families

- Landsat : bandes spectrales et indices de végétation ou d'eau.
- TerraClimate : variables climatiques et hydrologiques.
- Variables temporelles : année, mois, saison et semaine.
- Variables géographiques : coordonnées, distance à l'équateur et proximité côtière.
